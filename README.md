# 基督物理学个人研究主页

公开演示地址：https://danielwukun.github.io/

本站是 DanielWuKun 的个人研究与内容演示，讨论自然规律、主体同一性、古代文本与人类历史。

## 当前内容

- 旧约与人类学对照图谱：六个可选择主题，分别展示经文、材料、比较判断和外部来源。
- 英文影像随笔：After Christianity’s Bankruptcy, God Remains 1.2-v5，旁白版和无旁白版。
- 三篇入门笔记与主体同一性思想实验。

## 维护

静态 HTML、CSS、JavaScript，无构建依赖。发布来源为 main 分支根目录，`.nojekyll` 保留。

本地可运行 `python -m http.server 8765`，再访问 `http://localhost:8765`。不需要把 API 密钥、创业报告或私人书稿放入仓库。

`media/` 中为供网页播放的720p副本；原始1080p视频保存在作者本地，未被修改。播放采用原生浏览器播放器，不自动播放，不在首次打开首页时下载整部影片。
